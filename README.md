# 🎮 EchoMaze – A Sound-Based Puzzle Game
EchoMaze is a browser-based puzzle game where you navigate using sound, not sight. It's designed to simulate echolocation, forcing players to listen carefully to find their way through a maze.

# 🧠 Why I Made This
I built EchoMaze to challenge myself to think outside the box of traditional game design. Instead of relying on visuals like most games, I wanted to explore how players can interact with a game world using only audio feedback.

This project let me:

Practice creative problem solving with limited input/output

Learn how to use JavaScript audio APIs

Push myself to build something that's more than just fun — it's also unusual and experimental

It’s also my way of thinking about accessibility and how games might be designed for players with visual impairments or sensory differences.

# 🔧 Tech Stack
HTML & CSS for the structure and layout

JavaScript for game logic and sound

Audio API for feedback mechanics

# 🧪 What I Learned
Designing a game that relies on sound is hard — but really fun

Sound feedback can be just as meaningful as visuals when used well

Simple ideas can become unique with the right twist
